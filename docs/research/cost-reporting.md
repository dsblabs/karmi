# Cost reporting sources: who returns a per-request cost, where, and how karmi's `Usage.cost` maps to it

Research note, 2026-08-30, answering GitHub issue #29 (child of map #1). Primary sources only: developers.cloudflare.com (AI Gateway pages) read both live and from the `cloudflare/cloudflare-docs` repository (`production`, commit `3feb9a4`, 2026-08-28; shallow clone in `/tmp`), the Cloudflare REST API reference for AI Gateway logs, the `cloudflare/ai` repository (`main`, commit `917c024`, 2026-07-30; `packages/ai-gateway-provider` 4.0.0 and `packages/gateway-core`), openrouter.ai/docs, the `OpenRouterTeam/ai-sdk-provider` repository (`main`, commit `b96b207`, 2026-07-23; 3.0.0), vercel.com/docs/ai-gateway and ai-sdk.dev, the `vercel/ai` repository (`main`, commit `1c68540`, 2026-08-28; `packages/gateway` 4.0.68), platform.claude.com, the `anthropics/anthropic-sdk-typescript` repository (`main`, commit `7f3898c`, 2026-08-27; 0.122.0), the `openai/openai-node` repository (`main`, commit `eea2292`, 2026-08-28; 7.8.0), ai.google.dev, and the `badlogic/pi-mono` repository (`main`, commit `853a80d`, 2026-08-28; `packages/ai` 0.84.4). Every claim carries a bracket key from section 9; anything not verifiable from a primary source is marked UNVERIFIED. Glossary follows `CONTEXT.md`; prior notes are cited as [PS] (provider seam, whose §4 `Usage` this note extends) and issue #18 as [P18] (decision: `cost` is present only when a provider or gateway *reports* it; karmi ships no price table).

Date-sensitive: OpenRouter has **deprecated** `usage: { include: true }` and `stream_options.include_usage` — "Full usage details are always included" [OR-usage][OR-chat]; the OpenRouter AI SDK provider still sends `include_usage: true` in strict mode and still documents the `usage.include` setting [OR-prov-chat][OR-prov-readme]. Cloudflare's `/compat/chat/completions` is deprecated for single-model use in favour of `api.cloudflare.com/client/v4/accounts/{id}/ai/v1/chat/completions` (page last updated 2026-08-07) [AIG-compat]; Workers AI joined Unified Billing on 2026-08-07 [AIG-cl-ub]. Vercel's AI Gateway pricing page was updated 2026-08-23 and its REST reference 2026-08-27 [VG-pricing][VG-rest].

## 1. Summary and recommendation

**Recommendation: only two of the six sources return a per-request monetary cost in the response, and both do so on the final stream part — OpenRouter (`usage.cost`, a float in USD-denominated credits, in the last SSE chunk) and Vercel AI Gateway (`providerMetadata.gateway.cost`, a decimal *string* in USD, on the AI SDK `finish` part). Cloudflare AI Gateway never puts cost in the response; it computes an *estimate* into its log, reachable only by the REST logs API, the `getLog()` binding, Logpush or the dashboard, joined on the `cf-aig-log-id` response header. Anthropic, OpenAI and Gemini return tokens only. So `Usage.cost` is populated synchronously at `message_end` for the OpenRouter and Vercel-gateway adapters, is absent for direct Anthropic/OpenAI, and for Cloudflare AI Gateway karmi records the log id and leaves the cost join to the Platform.** Concretely:

1. **Cloudflare AI Gateway: log-only, estimated, USD-implied.** Docs: "The cost metric is an **estimation** based on the number of tokens sent and received … refer to your provider's dashboard for the most accurate cost details", and it exists "only for endpoints where the models return token data and the model name in their responses" [AIG-costs]. The log entry (`GET /accounts/{account_id}/ai-gateway/gateways/{gateway_id}/logs[/{id}]`) carries `cost` (optional number), `custom_cost` (optional boolean), `tokens_in`, `tokens_out`, `cached`, `metadata` (string), `provider`, `model`, `step`, `request_head`/`response_head` [CF-logs-list][CF-logs-get]. No response header carries cost: the documented response headers are `cf-aig-log-id`, `cf-aig-step`, `cf-aig-cache-status`, `cf-aig-dlp` (plus `cf-aig-run-id` seen only in `cloudflare/ai` source) [AIG-feedback][AIG-caching][AIG-dlp][CF-aigp-src]. `cf-aig-custom-cost` is a *request* header, JSON `{"per_token_in": n, "per_token_out": n}` (per token, unlimited decimals, e.g. `0.000001` for $1/M), which "override[s] the default or public model costs" for that request's log entry; it is not documented as echoed back, cache hits always log `0`, and it only applies "to requests that pass tokens in their response" [AIG-custom-cost]. Unit is never named in the schema; the custom-cost example and the spend-limits changelog ("$200/day budget") imply USD [AIG-custom-cost][AIG-cl-spend]. Unified Billing ("5% fee … on all credits purchased", "passed through with no markup", credits "deduct … in real time") does not expose the charged amount on the response; BYOK pages say nothing about cost reporting; spend limits "work with both Unified Billing and BYOK requests for models with known pricing", which implies the log cost is computed the same way regardless of key source (UNVERIFIED beyond that sentence) [AIG-ub][AIG-byok][AIG-cl-spend]. `cf-aig-event-id` does **not** appear anywhere in `cloudflare-docs`; it exists only as `eventId → cf-aig-event-id` ("Trace id for this event") in `@cloudflare/gateway-core` [CF-core-src] — treat it as UNVERIFIED for joining and use `cf-aig-log-id` (a response header, also `env.AI.aiGatewayLogId` for the last binding call) [AIG-feedback][AIG-binding].
2. **OpenRouter: in-body, always on, final chunk.** `usage: { prompt_tokens, completion_tokens, total_tokens, cost, cost_details: { upstream_inference_cost, upstream_inference_prompt_cost, upstream_inference_completions_cost }, is_byok, prompt_tokens_details: { cached_tokens, cache_write_tokens, audio_tokens }, completion_tokens_details: { reasoning_tokens, … } }`; `cost` is "Cost in credits", a nullable number, `upstream_inference_cost` is "only available for BYOK requests; otherwise it returns 0 or null" [OR-overview][OR-chat][OR-usage]. Streaming: "every stream ends with an extra chunk that carries the `usage` object … sent just before the `[DONE]` message"; that chunk has **one choice with a content-free delta** repeating `finish_reason`, not an empty `choices` array [OR-streaming]. No request opt-in is needed any more [OR-usage]. `GET /api/v1/generation?id=` returns `total_cost` (USD), `usage`, `cache_discount`, `upstream_inference_cost`, `is_byok`, native token counts, `streamed`, `cancelled`, `provider_name` — the docs state no propagation delay (UNVERIFIED that it is immediate) [OR-gen]. BYOK is billed at "5% of what the same model/provider would cost normally" above a $25k/month (pay-as-you-go) list-price allowance, deducted from credits [OR-byok].
3. **Vercel AI Gateway: in `providerMetadata.gateway`, decimal string, USD.** Documented output: `"cost": "0.0045405"`, `"marketCost": "0.0045405"`, `"generationId": "gen_…"` beside `routing` — "`gateway.cost` … is the inference cost for this request, returned as a decimal string. It does not include other charges (for example, Custom Reporting writes or Zero Data Retention surcharges)" [VG-filter]. `@ai-sdk/gateway` types the object as open (`GatewayProviderMetadata = { asyncJob?, [key: string]: JSONValue }`) and its `doStream()` forwards server-sent `LanguageModelV4StreamPart`s verbatim, so the cost rides on whatever part the server attaches it to — by AI SDK convention the `finish` part (UNVERIFIED in source; the gateway server is closed) [VG-meta-src][VG-lm-src]. The generation id is "injected into the first content chunk" on streams and the after-the-fact `GET /v1/generation?id=` returns `total_cost`, `market_cost`, `surcharge_cost`, `gateway_cost`, `upstream_inference_cost`, `is_byok` as **numbers**; "Usage events are ingested asynchronously, so a lookup issued immediately after the generation completes returns `Usage event not found`" [VG-rest][VG-usage][VG-geninfo-src]. BYOK: "no markup or fee"; `total_cost` "Does not include cost of BYOK requests", `upstream_inference_cost` is "Market list price cost for BYOK … Non-zero only for BYOK generations"; a failed BYOK call is retried on system credentials and *that* is charged [VG-rest][VG-byok][VG-pricing]. Whether `providerMetadata.gateway.cost` is `"0"` or the market cost on a BYOK request is UNVERIFIED.
4. **Anthropic direct: tokens only.** `Usage` in the SDK is `{ input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens, cache_creation: { ephemeral_5m_input_tokens, ephemeral_1h_input_tokens }, output_tokens_details: { thinking_tokens }, server_tool_use: { web_search_requests, web_fetch_requests }, service_tier, inference_geo }`; no field named cost/price/amount exists in the SDK's message types [AN-sdk-usage]. `usage.iterations` exists only in the beta namespace; `speed` is not a `Usage` field in the SDK (UNVERIFIED against the live reference page, which WebFetch truncated) [AN-sdk-beta]. Streaming: `message_start` carries the initial `usage` ("input_tokens": 25, "output_tokens": 1) and `message_delta` carries `MessageDeltaUsage` whose fields are documented as "cumulative" — the last `message_delta` is the one to read [AN-stream][AN-sdk-delta]. The Usage & Cost Admin API is org-level: usage buckets `1m`/`1h`/`1d` grouped by model, workspace, API key, service tier, `inference_geo`, `speed`; cost `1d` only, "All costs in USD, reported as decimal strings in lowest units (cents)"; data "typically appears within 5 minutes"; poll "once per minute"; Admin key required; nothing joins to a request id [AN-cost-api]. Neither `@anthropic-ai/sdk` nor `@ai-sdk/anthropic` has a cost helper (grep of both sources) [AN-sdk-usage][AI-anthropic-src].
5. **OpenAI direct: tokens only.** `CompletionUsage` / `ResponseUsage` carry tokens, cache details and a `compute_units?: number | null` ("Currently null when available"); no monetary field [OA-sdk-chat][OA-sdk-resp]. Chat Completions needs `stream_options: { include_usage: true }`: "an additional chunk will be streamed before the `data: [DONE]` message … the `choices` field will always be an empty array. All other chunks will also include a `usage` field, but with a null value … If the stream is interrupted, you may not receive the final usage chunk" [OA-sdk-chat]. Responses API: `response.completed` carries the full `Response` object including `usage` [OA-sdk-resp].
6. **Gemini and pi-ai.** `UsageMetadata` is `promptTokenCount`, `cachedContentTokenCount`, `candidatesTokenCount`, `toolUsePromptTokenCount`, `thoughtsTokenCount`, `totalTokenCount`, per-modality `*TokensDetails[]`, `serviceTier` — no cost; which streamed chunk carries it is UNVERIFIED [GG-usage]. pi-ai's `Usage.cost { input, output, cacheRead, cacheWrite, total }` is **computed**, not reported: `calculateCost(model, usage)` multiplies token counts by `model.cost` rates in `$/million tokens` (with tiers and a 2× rule for 1h cache writes) from a generated model table, and every adapter calls it (`anthropic-messages.ts` at `message_start` and on finish, `openai-completions.ts`, `google-generative-ai.ts`, `bedrock-converse-stream.ts`, …) [PI-calc][PI-types][PI-callers][PI-gen]. It is the price-table approach [P18] ruled out.

What follows for karmi: `Usage.cost` should be `{ amount: number; currency: "USD"; source: CostSource; basis: "billed" | "list" | "estimate" }` with `source` a closed union (§7), recorded at `message_end` by the OpenRouter and Vercel-gateway adapters only; the direct Anthropic adapter and Cloudflare AI Gateway paths record `gateway: { provider: "cloudflare"; logId }` instead, and karmi does **not** poll the Cloudflare logs API in v0.

## 8. `cost { amount, currency, source }` mapping per karmi adapter

Proposed shape, extending [PS §4]:

```ts
export type CostSource = "openrouter" | "vercel-gateway" | "cloudflare-gateway-log";

export interface Usage {
  // … token fields from [PS §4] …
  cost?: {
    amount: number;                 // parsed to number at the seam; keep raw string in `raw`
    currency: "USD";                // every verified source is USD or USD-denominated credits
    source: CostSource;
    basis: "billed" | "list" | "estimate";   // what the number means, see rows below
    upstream?: number;              // provider list cost when the source reports it (BYOK)
    byok?: boolean;
  };
  gateway?: { provider: "cloudflare" | "vercel" | "openrouter"; id: string };  // cf-aig-log-id | generationId | chat id
  raw?: unknown;
}
```

|---|---|---|---|---|---|---|
| Direct Anthropic (`@anthropic-ai/sdk`) | none; `usage` from the last `message_delta` (cumulative) merged over `message_start` | — | — | — | — | `cost` absent. Do not compute. Platform may reconcile with the Admin cost API per workspace/API key (org-level, daily) [AN-cost-api] |

Rules that fall out: (1) `cost` is written exactly once, at `message_end`, from the same stream part that yields tokens; (2) `basis` distinguishes Cloudflare's estimate from OpenRouter/Vercel's billed amounts so a Platform never adds an estimate to a bill; (3) Cloudflare custom costs are a Platform concern (it knows the negotiated rate) — karmi only passes `cf-aig-custom-cost` through `ProviderConfig.headers`; (4) no adapter multiplies tokens by a price [P18].

## 9. Open questions for the map

1. Does Cloudflare AI Gateway store `cf-aig-event-id` anywhere queryable, or is it purely a trace header? It is absent from the docs and present only in `gateway-core` [CF-docs-headers][CF-core-src]. Until answered, `cf-aig-log-id` and `cf-aig-metadata` are the only join keys.
2. What is the lag between response end and the log row (with `cost`) being readable via `GET …/logs/{id}` on streamed responses, and is `cost` populated for Unified Billing and BYOK requests identically? Needs an experiment; docs only imply it [AIG-cl-spend].
3. Does the Anthropic SDK stream helper expose response headers (`cf-aig-log-id`) without a second request? Check `client.messages.stream(...).withResponse()` / `asResponse()` in 0.122.0 (not read in this note).
4. On a Vercel AI Gateway BYOK request, is `providerMetadata.gateway.cost` `"0"`, the market cost, or absent? The REST `total_cost` excludes BYOK, `upstream_inference_cost` carries the list price [VG-rest]; the metadata value is unverified.
5. Should karmi ever emit a `usage.cost.reported` enrichment for Cloudflare logs, or is that entirely the Platform's job (it needs an API token with `AI Gateway Read` in the Worker)? This note recommends leaving it out of v0.
6. Is `speed` a `usage` field on the Messages response (the issue text assumes so), and does `usage.iterations` graduate from beta? Affects the [PS §4] `Usage.iterations` sketch [AN-sdk-beta].
7. Currency: every verified source is USD; should `currency` be a literal `"USD"` now, widened later, or an ISO-4217 string from day one?
