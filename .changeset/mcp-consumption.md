Remote MCP servers as a Tool source. A Scope (or the Deployment defaults) registers servers under `mcp.servers` with `auth: none | static` (static headers are credential references), allow/deny lists, `trustAnnotations` and a catalogue `ttlMs`; `egress.mcpHosts` (Deployment ∩ Scope) narrows what the Turn's `scopedFetch` may reach. A Spec references `mcp:<server>` or `mcp:<server>/<tool>`; at Turn start the Thread resolves the catalogues (refreshing stale ones, on `-32602`, or on `scope.mcp.refreshCatalog()`), offers the tools as `server__tool` grouped by server, and stamps `turn.started { toolsVersion }` with the per-server `catalogVersion`s. Clients connect lazily per Turn through `@modelcontextprotocol/client` 2.0.0 with `versionNegotiation: auto`, hold no listen stream and are dropped at Turn end; `input_required` is an error result and resource content is rendered with binary spilled to media. `scope.mcp.snapshot()` returns transport config and Sensitive static headers for one Turn. `createKarmi({ fetch })` injects the transport under every `scopedFetch`; the test kit adds `fakeMcpServer` (both spec eras) and `createTestKarmi({ mcpServers })`.
