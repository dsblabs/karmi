# @karmi/sandbox-container

`@karmi/sandbox-container` has the container image and the local runtime for the shell and Python Scripts of karmi.

Install the package:

```sh
pnpm add @karmi/sandbox-container
```

Read these pages of the karmi guide:

- [Sandbox](https://github.com/dsblabs/karmi/blob/main/docs/guide/07-sandbox.md) describes Scripts, the container sandbox and `LocalProcessSandbox`.
- [Deployment](https://github.com/dsblabs/karmi/blob/main/docs/guide/16-deployment.md) describes the container binding and the Wrangler configuration.

For contributors, [`INTERNALS.md`](https://github.com/dsblabs/karmi/blob/main/packages/sandbox-container/INTERNALS.md) describes the structure of the package.
