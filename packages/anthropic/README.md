# @karmi/anthropic

`@karmi/anthropic` is the karmi Provider for the Anthropic Messages API. It maps Provider Tools, for example web search, to their Anthropic definitions. A Provider profile can delegate Compaction to Anthropic.

Install the package:

```sh
pnpm add @karmi/core @karmi/anthropic
```

Read these pages of the karmi guide:

- [Providers](https://github.com/dsblabs/karmi/blob/main/docs/guide/05-providers.md) describes the Provider profiles and Cloudflare AI Gateway.
- [Tools](https://github.com/dsblabs/karmi/blob/main/docs/guide/03-tools.md) describes Provider Tools and their version pins.
- [Credentials](https://github.com/dsblabs/karmi/blob/main/docs/guide/12-credentials.md) describes credential references.
